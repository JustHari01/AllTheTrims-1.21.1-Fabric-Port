# All The Trims (UNOFFICIAL) — Fabric 1.21.1

An unofficial Fabric port of [All The Trims](https://modrinth.com/mod/allthetrims) for Minecraft 1.21.1. It carries forward the 1.21.0 Fabric implementation for players whose modpacks need the exact 1.21.1 release.

## Features

- Use items, including items from other mods, as armor trim materials.
- Apply trims to vanilla and modded armor.
- Support custom trim templates supplied by data packs and mods.
- Render trim colors dynamically instead of generating a separate texture for every material and pattern.
- Keep the original palette, animation, and renderer compatibility behavior.

## Requirements

- Minecraft Java Edition 1.21.1
- Fabric Loader 0.16.14 or newer
- Fabric API
- RuntimeTrims 1.0.6 or newer
- Java 21

Install the mod and its required dependencies on both the client and server. Mod Menu, REI, EMI, JEI, and Elytra Trims integrations are optional.
